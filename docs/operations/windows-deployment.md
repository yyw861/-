# Windows 门店部署与运维说明

## 运行环境

门店电脑只需安装 64 位 Java 21。安装后在 PowerShell 中运行 `java -version`，第一行应显示 21。Node.js 和 Maven 仅用于开发电脑构建发布包，门店电脑无需安装。

## 生成发布包

开发电脑需安装 Java 21、Maven 和 Node.js 24，并安装 Microsoft Edge 或 Playwright Chromium。在项目根目录执行：

```powershell
.\scripts\build-release.ps1
```

脚本会安装锁定版本的前端依赖，运行后端测试、前端单元测试、类型检查和完整端到端测试，再执行干净构建并生成 `dist\sportshop`。任何检查失败都会立即停止。发布包必须保持空数据；如果 `dist\sportshop\data` 已有文件，脚本会拒绝覆盖并保留原目录，请先把该运行实例整体移到安全位置，绝不能删除其 `data` 后强行构建。

## 门店首次启动

1. 将完整的 `sportshop` 文件夹复制到门店电脑的固定位置，例如 `D:\SportShop`。
2. 打开 PowerShell，进入该目录。
3. 如系统阻止本地脚本，仅对当前窗口运行 `Set-ExecutionPolicy -Scope Process Bypass`。
4. 执行 `.\start.ps1`。
5. 浏览器打开 `http://127.0.0.1:8080`。

程序、页面和 API 都包含在 `sportshop.jar` 中。数据库、备份和恢复失败日志保存在发布目录下的 `data` 文件夹，程序不会把业务数据写入用户主目录。

需要临时改用其他端口时，可执行 `.\start.ps1 -Port 18080`，并访问对应端口。默认仅监听本机 `127.0.0.1`。

## 扫码枪设置

普通 USB 扫码枪应使用“键盘输入”模式，并在条码末尾发送 Enter。入库时先选择商品分类，再扫描条码；未知条码会弹出快速建档窗口。零售收银页可直接连续扫码增加数量。

## 日常备份与升级

- 每天营业结束后在“系统设置 → 数据备份与恢复”创建一次手动备份，并定期把 `data\backups` 复制到另一块磁盘。
- 恢复会替换当前业务数据，系统会先创建恢复前保护备份。恢复过程中不要强制关闭程序。
- 升级前先停止程序并做手动备份。保留原 `data` 文件夹，只替换 `sportshop.jar`、`start.ps1` 和使用说明，然后重新启动。
- 不要在程序运行时手工复制或修改 `sportshop.db`、`sportshop.db-wal`、`sportshop.db-shm`。

## 常见问题

- 提示找不到 Java：安装 Java 21，并重新打开 PowerShell；再次确认 `java -version`。
- 8080 端口被占用：关闭占用程序，或用 `-Port` 参数启动到其他端口。
- 局域网其他电脑需要访问：明确执行 `.\start.ps1 -BindAddress 0.0.0.0`，在 Windows 防火墙中仅对受信任的门店网络放行所用端口，再使用运行电脑的局域网 IP。当前版本没有登录验证，开启后同一网络中的设备可能访问全部业务接口，绝不能暴露到互联网。
- 页面无法打开：先查看启动窗口中的错误；再访问 `/api/health`，正常结果为 `{"status":"UP"}`。
- 数据异常：不要直接编辑数据库文件，优先使用系统内的备份预检和恢复功能。
